# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a Bash-based calculator that calculates simple interest based on the values entered by the user. It provides a simple and interactive way to perform the calculation using the command line.

## Objective

The objective of this project is to develop a simple Bash script that accepts the required input values from the user and calculates the simple interest accurately.

## Formula

The simple interest is calculated using the following formula:

**Simple Interest = (Principal × Rate of Interest × Time) / 100**

## Input Fields

The calculator requires the following inputs:

1. **Principal (P)** – The initial amount of money.
2. **Rate of Interest (R)** – The rate of interest in percentage.
3. **Time (T)** – The time period for which the interest is calculated.

## Working

The calculator prompts the user to enter the principal amount, rate of interest, and time period. These values are used in the simple interest formula to calculate the interest.

## Output

The calculator displays the calculated simple interest based on the values provided by the user.

## Example

If:

- Principal = 1000
- Rate of Interest = 5%
- Time = 2 years

Then:

**Simple Interest = (1000 × 5 × 2) / 100 = 100**

Therefore, the calculated simple interest is **100**.
